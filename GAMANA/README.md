# AUREL — Modern Luxe Shopify theme

A designer-led Online Store 2.0 theme for a premium fashion or beauty client store. The sample brand name, copy, and imagery are placeholders; the real store's name, products, and brand assets will replace them.

## Start here

- [`docs/START-HERE.md`](docs/START-HERE.md) — plain-English guide and simple instructions.
- [`docs/DESIGN-DECISIONS.md`](docs/DESIGN-DECISIONS.md) — the choices already agreed and what is still a placeholder.
- `preview/` — a clickable visual concept using sample content. Its cart and email form are demonstrations, not connected to Shopify.

`GAMANA/` is the Shopify theme root: its standard theme folders are `assets/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, and `templates/`. `preview/` and `docs/` are excluded from Shopify theme uploads by `.shopifyignore`. Run Shopify theme tools from inside `GAMANA/`.

## Foundation

The theme uses Shopify Dawn 16.0.0 as a starting point for standard product, collection, search, cart, accessibility, and theme-editor behavior. The AUREL sections and visual layer provide the modern-luxe art direction. See [`LICENSE.md`](LICENSE.md) for the included Dawn license.

Nothing is published live without the store owner's explicit approval.
