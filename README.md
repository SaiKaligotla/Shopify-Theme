# GAMANA — Shopify theme

GAMANA is a Shopify Online Store 2.0 theme. **The Shopify theme root is this repository root**: `assets/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, and `templates/` are directly here. No `GAMANA/` parent folder is required.

- `Shopify-Theme.zip` is the upload package. Its archive root contains Shopify's theme folders directly.
- Open `index.html` on a static host to view the visual prototype in `preview/`.
- Run Shopify CLI and Theme Check from the repository root, for example: `npx --yes @shopify/cli@latest theme check --path .`.
- Project notes are in [`docs/START-HERE.md`](docs/START-HERE.md) and [`docs/DESIGN-DECISIONS.md`](docs/DESIGN-DECISIONS.md).

The visual direction takes high-level cues from Apple's product storytelling—quiet navigation, strong campaign imagery, generous whitespace, clear product groupings, and simple calls to action—without using Apple branding or assets.
