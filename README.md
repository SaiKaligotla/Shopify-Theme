# AUREL — Shopify theme

AUREL is a Shopify Online Store 2.0 theme. The Shopify theme source is in [`GAMANA/`](GAMANA/), and the storefront design preview is in [`GAMANA/preview/`](GAMANA/preview/).

- Open `index.html` from a static host to land on the storefront preview instead of a directory/404 route.
- `Shopify-Theme.zip` is the Shopify upload package. Its archive root contains the theme folders (`assets/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, and `templates/`); it is not a ZIP of the Git repository.
- For Shopify CLI commands, run them from inside `GAMANA/`, which is the theme root.

The visual direction takes high-level cues from Apple's product storytelling—quiet navigation, strong campaign imagery, generous whitespace, clear product groupings, and simple calls to action—without using Apple branding or assets. See [`GAMANA/docs/START-HERE.md`](GAMANA/docs/START-HERE.md) for the handoff guide and [`GAMANA/docs/DESIGN-DECISIONS.md`](GAMANA/docs/DESIGN-DECISIONS.md) for the design notes.
